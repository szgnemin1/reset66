[ ANDROID APK DERLEME ALTYAPISI ]

GitHub Actions Cloud Pipeline

Bu depoyu GitHub'a yüklediğinde `.github/workflows/build-apk.yml` otomatik çalışır ve Releases bölümünden doğrudan imzalı Android APK dosyasını indirmeni sağlar.

name: Build Reset66 Android APK
on:
  push:
    branches: [ master, main ]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npx cap sync android
      - uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'
      - run: cd android && ./gradlew assembleDebug
      - uses: actions/upload-artifact@v4
        with:
          name: reset66-debug-apk
          path: android/app/build/outputs/apk/debug/app-debug.apk
