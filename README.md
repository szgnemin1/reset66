## 🚀 Eklenen 3 Dev Modül

### 🧘 Modül 1: Gelişmiş Meditasyon & Frekans Stüdyosu
* **Binaural Vuruşlar:** Sol/Sağ kulak faz farkıyla Alfa (10 Hz), Teta (6 Hz), Gama (40 Hz).
* **Ortam Gürültüsü:** Algoritmik Pembe Gürültü (yağmur hissi) ve Kahverengi Gürültü (dalga/derin uğultu).
* **Tibet Çanı (Singing Bowl):** 432 Hz Solfeggio harmonikleri ile üstel akustik sönümlenme.
* **Ritmik Nefes Küresi:** Kutu Nefesi (4-4-4-4), 4-7-8 ve Wim Hof ritimleri + her fazda hafif haptik rehberlik.
* **KeepAwake:** Meditasyon sırasında ekran kararmaz.

### 🏋️ Modül 2: Kendi Spor Programını Oluşturma & Dinlenme Sayacı
* **7 Günlük Workout Builder:** Gün bazında itiş/çekiş/bacak hedefleri, set sayısı, tekrar ve ağırlık girişi.
* **Hazır Şablonlar:** PPL (6 Gün), Full Body (3 Gün), Calisthenics (Vücut Ağırlığı), Upper/Lower (4 Gün).
* **Canlı Antrenman Takibi:** Set butonuna basıldığında dokunsal haptik onay.
* **Otomatik Dinlenme Sayacı:** 30s/60s/90s/120s geri sayım, süre bitiminde antrenör düdüğü ve güçlü haptik titreşim.
* **Kritik Boss Hasarı:** Antrenman tamamlandığında toplam kaldırılan hacim üzerinden Boss'a **80 Kritik Hasar**.

### ⌚ Modül 3: Akıllı Saat & Google Health Connect Entegrasyonu
* **Google Health Connect:** Android 14+ yerel uyku ve nabız izinleri (`READ_SLEEP`, `READ_HEART_RATE`, `READ_STEPS`).
* **Web Bluetooth BLE GATT:** Nabız bantları ve saatler (`0x180D`, `0x2A37`, `0x180F`).
* **Dosya İçe Aktarma:** Google Takeout, Samsung Health, Mi Fitness, Apple Health JSON/CSV otomatik ayrıştırıcı.
* **Buff/Debuff:**
  * Uyku Skoru $\ge 80$: **"Tam Dinlenmiş"** (+%15 XP Çarpanı, VIT/WIL +3).
  * Uyku Süresi $< 6$ Saat: **"Tükenmişlik"** (-%10 XP Cezası).

## 🛠️ Kurulum & Android APK Derleme

### Yöntem A: GitHub Actions ile Tek Tıkla Bulutta Derleme (Önerilen)
1. Bu depoyu GitHub hesabınıza forklayın veya push edin.
2. Deponuzun **Actions** sekmesine gidin.
3. **Build Reset66 Android APK** iş akışını çalıştırın (veya `git push` yaptığınızda otomatik başlar).
4. İş akışı tamamlandığında **Artifacts** bölümünden `Reset66-LifeReset-Android-Debug-APK` dosyasını indirip doğrudan Android telefonunuza kurun!

### Yöntem B: Yerel Geliştirici Ortamı (Terminal)
Gereksinimler: Node.js 18+, JDK 17, Android Studio / Android SDK.

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Capacitor Android projesini senkronize edin
npx cap sync android

# 3. Android APK derleyin (Debug)
cd android
./gradlew assembleDebug

# Çıktı APK:
# android/app/build/outputs/apk/debug/app-debug.apk
```
